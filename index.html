Can you explain how AVL tree rotations work?

Great question! AVL tree rotations are used to maintain balance. There are 4 types:

1. Left Rotation (LL) — When right subtree is heavy
2. Right Rotation (RR) — When left subtree is heavy
3. Left-Right (LR) — Double rotation
4. Right-Left (RL) — Double rotation

Balance Factor = height(left) - height(right)
If BF > 1 or BF < -1, rotation needed!
